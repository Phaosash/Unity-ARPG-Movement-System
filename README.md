<h2>Overview</h2>

This project is an Action RPG (ARPG) movement system developed in Unity 6.6, designed to provide responsive, mouse-driven character movement inspired by classic ARPGs.
The system uses Unity's NavMesh navigation for pathfinding, alongside additional movement mechanics and camera controls to create an intuitive gameplay experience.

<h2>Features</h2>
NavMesh Navigation – Click-to-move character navigation using Unity's NavMesh system.<br>
Character Rotation – Hold the right mouse button to rotate the character towards the mouse cursor.<br>
Sprint Movement – Hold the middle mouse button to increase character movement speed.<br>
Camera Zoom – Scroll the mouse wheel to smoothly zoom the camera in and out.<br>
Camera Follow – Camera smoothly tracks the player character throughout gameplay.<br>
ARPG-Style Controls – Mouse-driven movement and rotation inspired by traditional Action RPGs.<br>

<h3>Controls</h3>
<h4>Input Action</h4>
Left Mouse Button	Move character using NavMesh<br>
Right Mouse Button (Hold)	Rotate character towards mouse cursor<br>
Middle Mouse Button (Hold)	Sprint<br>
Mouse Scroll Wheel	Zoom camera in / out<br>

<h2>System	Description</h2>
<h3>Navigation</h3>
Handles character movement and pathfinding across the environment.
<h3>Rotation</h3>
Allows the character to rotate towards the mouse cursor while holding RMB.
<h3>Sprinting</h3>
Increases movement speed while holding MMB.
<h3>Camera</h3>
Follow	Keeps the camera tracking the player character.<br>
Zoom	Allows adjustable camera distance using the mouse scroll wheel.
